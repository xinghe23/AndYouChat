# 测试任务清单 · P0 + P1

> 对象：AndYouChat 后端（账号 / 好友 / 单聊实时消息）+ 网页调试台
> 目的：在写 Android 之前锁死后端行为，Android 只需对齐协议，不再回头改服务端

## 0. 当前基线（2026-10-30）

| 项目 | 结果 |
|---|---|
| 自动化测试 `pytest tests` | **41 项全部通过**，耗时 7.3s |
| 端到端冒烟 `scripts/smoke_test.py` | **16 项全部通过**（真实 HTTP + WebSocket） |
| 数据库 | SQLite（NullPool + WAL）；MySQL 8 待 Docker 起来后复测 |
| Redis | fakeredis（进程内）；Redis 7 待 Docker 起来后复测 |

**结论：P0 + P1 后端功能可用，可以开始 Android 端。** MySQL / Redis 真实环境需补一轮（见 ENV-03）。

## 1. 环境准备

| 编号 | 任务 | 命令 | 预期 |
|---|---|---|---|
| ENV-01 | 安装依赖 | `python -m venv .venv && ./.venv/Scripts/python.exe -m pip install -r requirements.txt` | 无报错 |
| ENV-02 | 零依赖启动 | `./.venv/Scripts/python.exe -m uvicorn app.main:app --port 8200` | `/health` 返回 `db:true, redis:true` |

| ENV-05 | 打开接口文档 | `http://127.0.0.1:8200/docs` | 18 个接口可展开 |

> 本机有 `HTTP_PROXY` 时，浏览器访问 127.0.0.1 正常，但命令行工具需 `NO_PROXY=127.0.0.1,localhost`。

## 7. 边界与异常（EDGE）

| 编号 | 用例 | 预期 | 结果 |
|---|---|---|---|
| EDGE-01 | 空消息 / 全空格发送 | 不发出请求，输入框保留内容 | ☐ |
| EDGE-02 | 4096 字符长消息 | 正常发送或明确报错，不静默截断 | ☐ |
| EDGE-03 | 换行与小写 emoji | 保留换行，不乱码 | ☐ |
| EDGE-04 | `client_msg_id` 少于 8 位 | WS 返回 `error`，HTTP 返回 422 | ☐ |
| EDGE-05 | 并发同一 `client_msg_id`（两端同时发） | 唯一键拦截，只落一条，两端都拿到 ack | ☐ |
| EDGE-06 | `user_id` 超出 Int 范围 | Kotlin 用 Long 能正确解析（不可用 Int） | ☐ |
| EDGE-07 | 会话 ID 不存在 | 404 / 403，不 500 | ☐ |
